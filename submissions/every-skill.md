# Every Skill library

Source: [Submission page](https://skills.every.to/submit), read on 2026-11-04.

The page asks for a sign-in, a package with a root `SKILL.md`, and optional scripts, references and assets.
AI checks assess safety and quality, then a person approves or asks for changes.

## Package

Export the directory `skills/fax-for-agents` so that `SKILL.md` sits at the package root.
The `references/` folder travels with it. Nothing else is needed.

```bash
cd skills && zip -r ../fax-for-agents-every-skill.zip fax-for-agents
```

The accepted archive format is not stated on the public page. Check the upload control after sign-in.
